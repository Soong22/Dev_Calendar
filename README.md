# 📅 Dev Calendar

> 개발자 및 업무 관리자를 위한 프로젝트 중심 업무 캘린더

기존 일정 관리 앱은 일정을 기록하는 데 초점이 맞춰져 있습니다.

하지만 실제 업무에서는 **프로젝트별 진행 상황**, **오늘 해야 할 일**, **진행 중인 프로젝트**, **완료된 작업** 등을 함께 관리해야 합니다.

Dev Calendar는 이러한 문제를 해결하기 위해 만든 **프로젝트 중심 업무 캘린더**입니다.

---

# 프로젝트 목표

- 프로젝트 단위 업무 관리
- 캘린더 기반 일정 관리
- 진행 상황 시각화
- 할 일(Check List) 관리
- 여러 플랫폼(Mac / Windows / iPhone / Web) 지원
- 향후 AI 기반 업무 요약 기능 지원

---

# 주요 기능

## 📅 Calendar

- 월 / 주 / 일 보기
- 프로젝트별 일정 표시
- 프로젝트별 색상 태그
- 일정 클릭 시 상세 정보 확인
- Drag & Drop 일정 변경 (예정)

## 📂 프로젝트 관리

- 프로젝트 생성
- 프로젝트별 색상 지정

## 🚨 진행 중 프로젝트 알림

아직 완료되지 않은 프로젝트가 있다면

```
진행 중인 프로젝트가 있습니다.

OCR Parser

Batch 자동화
```

처럼 표시됩니다.
